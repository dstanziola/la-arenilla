## Especificaciones de Componentes

### Tarjeta de Servicio
```
┌─────────────────────────┐
│  [ICONO]                │ ← Emoji o icono SVG
│                         │
│  Nombre del Servicio    │ ← h3, bold
│                         │
│  Descripción breve del  │ ← p, 2-3 líneas max
│  servicio ofrecido      │
│                         │
│  $XX / unidad           │ ← span, destacado
│                         │
│  [ Consultar ]          │ ← Botón → WhatsApp
└─────────────────────────┘

Dimensiones:
- Móvil: 100% ancho
- Tablet: ~48% ancho
- Desktop: ~31% ancho
- Padding: 1.5rem
- Border-radius: 8px
- Sombra sutil
```

### Botón WhatsApp Flotante
```
┌───────┐
│  💬   │
│       │
└───────┘

Especificaciones:
- Tamaño: 56px x 56px
- Border-radius: 50%
- Color: #25D366 (WhatsApp green)
- Posición: fixed, bottom 20px, right 20px
- Z-index: 1000
- Sombra: 0 4px 12px rgba(0,0,0,0.15)
- Hover: scale(1.1)
```

### Header
```
Especificaciones:
- Altura: 60px móvil, 70px desktop
- Posición: fixed top
- Background: blanco con sombra sutil
- Z-index: 999
```
